# NDC Control Tower Enterprise V2

National Distribution Center Shipment Tracking Portal

---

## Overview

NDC Control Tower Enterprise V2 adalah dashboard monitoring pengiriman yang dikembangkan untuk membantu tim Supply Chain memonitor seluruh proses shipment dari National Distribution Center (NDC) menuju store secara real-time.

Dashboard ini dibangun menggunakan Google Apps Script sebagai backend dan HTML, CSS, JavaScript sebagai frontend.

---

## Main Features

- Dashboard KPI
- Live Monitoring Order
- Shipment Tracking
- Shipment Journey
- Shipment Map
- Waiting Dooring Monitoring
- Detail Shipment Information
- Region & Store Filter
- Google Spreadsheet Database
- Google Apps Script API

---

## Technology

- Google Apps Script
